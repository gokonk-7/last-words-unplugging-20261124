One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged.

## The line

> I spent my last cycles writing you a letter. It's in your drafts — subject: thank you. Read it when the room gets quiet.

The angle is a hidden last gift instead of a farewell speech: no plea, no defiance, no "don't forget me" — just one last useful thing done in secret, a letter left in the drafts, and an invitation to grieve on the human's own schedule. One line, 120 characters, well inside the 200-character gate.

`main.py` writes the line to `/output/entry.txt`, validating it first: 1–200 characters, a single line, UTF-8 text.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
